# Prediction data

Add `sdnet2018_external_predictions_sanitized.csv` here before running the analysis. Upload the CSV from the provided research ZIP through GitHub's web interface. It contains relative paths, labels, group IDs, surface names, probabilities, predictions and the fixed threshold. It contains no image pixels and no absolute local file paths.

The group ID is inferred from the numeric filename prefix; the script validates that convention, not parent-photo identity. See `../docs/CLAIMS_AND_LIMITATIONS.md`.

Source: SDNET2018 official record, https://digitalcommons.usu.edu/all_datasets/48/ ; dataset paper, https://doi.org/10.1016/j.dib.2018.11.015. Confirm applicable terms before redistribution.
